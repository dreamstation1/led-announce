# led-announce

[led](https://github.com/dreamstation1/led) 버스 앱의 노선 안내방송 내보내기 도구.

- 주소: https://dreamstation1.github.io/led-announce/ (led 앱 노선 화면의 "🎙 방송 제작" 버튼으로 열림, `?route=<ROUTE_ID>`)
- 노선을 불러오면 정류소가 순서대로 채워지고(가상 정류소 제외), 한 줄에 하나씩 직접 고칠 수 있다.
- 정류소마다 `이번정류소 → 정류소 → 다음정류소 → 다음 정류소 → thisstopis → 정류소 (1)` 을 이어 붙인 WAV를 만든다.
  마지막 줄은 `이번정류소 → 정류소 → thisstopis → 정류소 (1) → 종착`.
- 녹음(led/audio)이 없으면 시뮬레이션과 같은 AI 음성 서버로 만들고, 음량 맞춤·무음 정리·간격(0.18초/0.45초)도 시뮬레이션과 같다.
- 정류소 데이터, 녹음 목록, 영어 제외 목록, 글자 다듬기·번역 규칙은 실행할 때 led 사이트에서 그대로 읽어 온다(따로 맞출 필요 없음).
